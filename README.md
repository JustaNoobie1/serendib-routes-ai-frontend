# SerenAI Frontend

React + Vite frontend for SerenAI, a conversational RAG travel assistant for Sri Lanka.

## Live Demo

https://serendib-routes-ai-frontend.vercel.app/

## Backend

https://github.com/JustaNoobie1/serendib-routes-conversational-rag

## Features

- Responsive chat UI
- Multi-turn conversation support
- Session-based thread persistence
- Markdown rendering
- New conversation handling
- FastAPI backend integration

## Tech Stack

- React
- Vite
- React Markdown
- Vercel
